# 🌍 Мультиязычность бота

Бот поддерживает **4 языка**:
- 🇷🇺 Русский (ru)
- 🇬🇧 Английский (en)
- 🇨🇳 Китайский (zh)
- 🇸🇦 Арабский (ar)

## Как работает

Язык определяется **автоматически** из:
1. Команды офера (`офер англ`, `офер en`)
2. Языка Telegram пользователя (`language_code`)
3. По умолчанию - русский

## Что переведено

✅ **Все сообщения бота:**
- Приветствие и подписка на канал
- Инструкции
- Тексты оферов
- Кнопки (Принять, Отклонить, Передать, Подтвердить)
- Уведомления о продаже
- Подтверждения передачи
- Ошибки

## Примеры команд

### Русский (по умолчанию)
```
офер https://t.me/nft/PartySparkler-140864 150 грам
```

### Английский
```
офер англ https://t.me/nft/PartySparkler-140864 150 gram
офер en https://t.me/nft/PartySparkler-140864 150 gram
```

### Китайский
Автоматически определяется по `language_code` = "zh"

### Арабский
Автоматически определяется по `language_code` = "ar"

## Файлы

- `translations.py` - все переводы
- `bot.py` - использует функцию `t()` для перевода

## Добавление нового языка

1. Открой `translations.py`
2. Добавь новый ключ в `TRANSLATIONS` (например, `"es"` для испанского)
3. Скопируй структуру из `"ru"` и переведи все тексты
4. Добавь проверку в функцию `get_user_locale()`

## Технические детали

```python
from translations import t, get_user_locale

# Получить перевод
text = t("welcome", locale="en")

# С параметрами
text = t("offer_text", locale="ru", amount="1000₽")

# Определить язык пользователя
locale = get_user_locale(message)
```
