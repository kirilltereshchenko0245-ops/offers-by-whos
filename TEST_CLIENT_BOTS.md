# Тестирование системы клиентских ботов

## Шаг 1: Запуск главного бота

```powershell
cd c:\Users\Лена\Desktop\offer_bot
python bot.py
```

Должно появиться:
```
INFO Loading client bots...
INFO OfferBot starting; owner_id=...
```

## Шаг 2: Проверка доступа

В главном боте отправь:
```
/codeoffer free
```

Должно появиться:
```
✅ Доступ к оферам выдан!
```

## Шаг 3: Создание нового бота

1. Открой @BotFather
2. Создай нового бота: `/newbot`
3. Назови его: `My NFT Bot`
4. Username: `my_nft_test_bot`
5. Скопируй токен

## Шаг 4: Добавление бота

В главном боте отправь:
```
/mybots
```

Должна появиться кнопка "➕ Добавить бота"

Нажми на неё, затем:
```
/addbot
```

Должно появиться:
```
🤖 Добавление бота

1. Создайте нового бота через @BotFather
2. Скопируйте токен бота
3. Отправьте его мне

Токен выглядит так:
1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

Отправьте /cancel для отмены.
```

Отправь токен от @BotFather

Должно появиться:
```
⏳ Проверяю токен...
✅ Бот добавлен!

@my_nft_test_bot
ID: 1

Теперь подключите к нему Telegram Business...
```

## Шаг 5: Проверка что бот запущен

В главном боте админ может проверить:
```
/botlist
```

Должно показать:
```
📱 Все клиентские боты

🟢 @my_nft_test_bot
ID: 1
Owner: [твой ID]
Active: ✅
```

## Шаг 6: Подключение Business

1. Открой настройки Telegram
2. Telegram Business → Business Messages
3. Выбери своего нового бота `@my_nft_test_bot`
4. Подключи

## Шаг 7: Тест офера

Отправь в Business чат (через твоего нового бота):
```
купить https://t.me/nft/PartySparkler-140864 150 грам
```

Должен создаться офер!

## Шаг 8: Проверка списка ботов

```
/mybots
```

Должен показать твоего бота со статусом 🟢 Запущен

## Проверка ошибок

### Если бот не запускается

Проверь логи:
```
[BOT 1] Started for user 123456789
```

Если ошибка токена:
```
[BOT 1] Failed to start: ...
```

### Если офер не создаётся

Проверь что:
1. ✅ Telegram Business подключен к клиентскому боту
2. ✅ У владельца бота есть доступ (`/codeoffer free`)
3. ✅ Бот запущен (🟢 в `/mybots`)

### Если команда /addbot не работает

Проверь что:
1. ✅ У тебя есть доступ (`/codeoffer free`)
2. ✅ У тебя меньше 5 ботов
3. ✅ Главный бот запущен с MemoryStorage

## Админские команды

```bash
# Список всех ботов
/botlist

# Остановить бота
/stopbot 1

# Запустить бота
/startbot 1

# Удалить бота
/deletebot 1
```

```
INFO [BOT 1] OFFER ACCEPT offer_id=1
```

## Типичные ошибки

### "❌ У владельца бота истёк доступ"
Владельцу бота нужно выдать доступ через `/codeoffer free`

### "❌ Для офера сначала подключите Telegram Business"
Business не подключен к клиентскому боту

### "❌ Достигнут лимит ботов (максимум 5)"
Удали старые боты через кнопку 🗑 в `/mybots`

### "❌ Этот токен уже используется"
Токен уже добавлен, используй другого бота
